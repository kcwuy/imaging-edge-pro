- 白底红字图标，保留熟悉的 IEM 构图与名称。

## 开始使用

1. 下载 APK 并安装。此前同签名修改版可覆盖；官方版因签名不同，不能直接覆盖，卸载前请先备份照片与设置。
2. 在相机上开启「智能手机连接」，让手机连接相机显示的 Wi-Fi。
3. 打开应用，选择相机，开始遥控拍摄或导入照片。

围绕 ZV-E10 调整，其他机型请自行确认。后台保持连接修复在此前版本实测有效；v3.3 尚未完成相机连接与拍摄实测。
