# 修改代码

这里保留 v3.3 新增的 Java 界面、后台连接保持代码及界面资源，供查阅。`icon-colors` 是此次白底红字的桌面图标资源。

这不是可直接由 Android Studio 编译的完整工程。原版 APK、反编译源码、构建工具、签名文件及个人测试照片均不在仓库中。安装包请到仓库首页下载。

发布包：`7.8.6-product.3.3`（`786260834`）。原 V3.3 构建通过 1039 项成品静态检查、485 套原布局契约与 96 项后台代码主机断言。白色图标版仅替换 8 张桌面图标 PNG 并重新签名，其余 APK 成员内容完全一致，签名证书保持不变。核对记录见 `icon-verification.json`；这些检查不能替代手机与相机实测。

APK SHA-256 随安装包一同放在 Releases。
